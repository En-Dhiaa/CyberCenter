# وثيقة نظرة عامة على المشروع (Project Overview)
## نظام CyberCenter لإدارة مراكز الإنترنت وصالات الألعاب

---

## 1. الرؤية والأهداف (Vision & Core Objectives)

يهدف مشروع **CyberCenter** إلى إعادة صياغة معايير إدارة مراكز الإنترنت وصالات ألعاب الـ eSports والأجهزة الشخصية (Gaming Lounges) في البيئات التجارية والتنافسية الحديثة. تعاني أغلب الأنظمة التجارية المتوفرة حالياً من مشاكل مزمنة تشمل:
- واجهات كلاسيكية قديمة تعود لعصر ويندوز XP/7 ولا تواكب هوية الألعاب الحديثة.
- ثغرات أمنية تتيح للعملاء تجاوز أوقات الجلسات أو الوصول إلى لوحة تحكم ويندوز وتخريب ملفات النظام.
- تعارض تقنيات الحماية مع أنظمة الـ Anti-Cheat (مثل Riot Vanguard، Easy Anti-Cheat، BattlEye) مما يتسبب في حظر حسابات اللاعبين أو شاشات زرقاء (BSOD).
- غياب الدقة المحاسبية وتسرب الإيرادات عند انقطاع الاتصال أو عند عدم ترابط المتجر الداخلي ونقاط البيع مع وقت الجلسات.
- ضعف مراقبة استهلاك الشبكة وتكلفة الطاقة الفعلية.

**CyberCenter** يقدم حلاً هندسياً متكاملاً يتصدى لهذه التحديات جذرياً عبر:
1. **معمارية مركزية حديثة (Centralized Modular Monolith):** خادم خلفي فائق الأداء بـ ASP.NET Core وقاعدة بيانات PostgreSQL، مع بروتوكول اتصال فوري SignalR.
2. **واجهة إدارة وتحكم مظلمة فاخرة (Dark Premium Web Dashboard):** بنيت بأحدث تقنيات React وTypeScript لدعم العمليات الإدارية والمحاسبية والمراقبة اللحظية مع دعم كامل للغة العربية (RTL) والإنجليزية (LTR).
3. **حزمة عميل ويندوز آمنة وذكية (Windows Client Suite):** تفصل بين خدمة النظام الحساسة (Windows Service) وواجهة التفاعل المكتبية (Gaming Shell) وشريط التراكب الشفاف (HUD) بما يضمن الأمان التام دون انتهاك قيود حماية الألعاب.

## 2. النطاق والبيئات المستهدفة (Scope & Target Environments)

النظام مصمم خصيصاً للعمل في:
- صالات الألعاب الاحترافية ومراكز استضافة بطولات الرياضات الإلكترونية (eSports Arenas).
- مقاهي الإنترنت ومراكز خدمات الطلاب والأعمال (Cyber & Business Cafés).
- نوادي ومراكز الترفيه الجماعي ومحطات ألعاب الواقع الافتراضي و PC Gaming.

## 3. الأطراف المستفيدة وأدوار المستخدمين (User Personas)

| الدور (Role) | الوصف والمسؤوليات الرئيسية |
| :--- | :--- |
| **مالك المركز / المدير العام (Super Admin)** | يمتلك الصلاحية الكاملة على إعدادات المركز، تسعير الباقات وساعات اللعب، إدارة حسابات الموظفين، اعتماد التعديلات المالية، إقفال الفترات المحاسبية الشهرية، والتحكم في إعدادات النسخ الاحتياطي والشبكة. |
| **مشرف الوردية / المحاسب (Admin / Cashier)** | المسؤول المباشر عن استقبال الزوار، فتح الجلسات اليدوية، إصدار وشحن الكروت المؤقتة، بيع وتجهيز طلبات المتجر والمأكولات، استلام المدفوعات النقدية والمحلية، وتقديم الدعم الفني الميداني. |
| **المشترك الدائم (Member)** | عضو يمتلك حساباً مخصصاً (اسم مستخدم وكلمة مرور مشفرة)، يحتفظ برصيد زمني أو اشتراك دوري (يومي/أسبوعي/شهري)، يتمتع بمساحة ملفات شخصية مخصصة، ويستطيع طلب المأكولات ومراجعة استهلاكه من حسابه. |
| **الزائر المؤقت (Guest User)** | عميل يدخل بواسطة كرت مؤقت مشفر بـ PIN عشوائي من 16 رقماً، أو عبر جلسة مفتوحة تفتحها الإدارة، ويحصل على بيئة استخدام معزولة ومؤقتة يتم تنظيفها تلقائياً عند انتهاء الجلسة. |
| **نظام المطبخ / البوفيه (Kitchen Station)** | شاشة مخصصة لعرض وإدارة طلبات المأكولات والمشروبات الموجهة من أجهزة الزوار وتحديث مراحل تجهيزها وتسليمها لحظياً. |

## 4. المكونات الرئيسية للنظام (Core Subsystems)

### 4.1. محرك إدارة الأجهزة والجلسات (Device & Session Engine)
- اكتشاف تلقائي لمحطات العمل وتسجيلها بـ Unique Device ID وبصمة عتادية.
- مراقبة نبض الجهاز (Heartbeat) وتحديث حالته اللحظية (Available, Occupied, Reserved, Maintenance, Offline, Locked).
- إدارة ثلاثية للجلسات:
  - **Open Session:** جلسة مفتوحة بإشراف الإدارة وتحسب بالتكلفة المتراكمة.
  - **Temporary Cards:** كروت مسبقة الدفع بـ PIN عالي التشفير ومدد مخصصة مع طباعة احترافية.
  - **Members:** اشتراكات دائمة بخصومات ومستويات ولاء وتجديد آمن.

### 4.2. لوحة الإدارة المتطورة (Web Admin Dashboard)
- واجهة Dark Premium تفاعلية مستوحاة من منصات القيادة الحديثة.
- شبكة الأجهزة الحية (Live Grid & Table View) مع تحكم شامل وفوري (فتح، قفل، تمديد، رسائل تنبيهية، إعادة تشغيل).
- نقطة بيع متطورة للمتجر الداخلي مع شاشة خاصة بالمطبخ وتتبع لحظي لمراحل الطلب.
- وحدة محاسبية صارمة تمنع التلاعب بالقيود المالية، وتدعم تسويات الإيرادات والمصروفات والإقفال الشهري المعتمد.
- نظام تقارير استهلاك الإنترنت وتقدير تكلفة الكهرباء (بين قراءات العدادات الذكية والتقدير الحسابي).

### 4.3. حزمة أجهزة العملاء (Windows Client Application)
- **CyberCenter.Agent:** خدمة نظام (Windows Service) تعمل بصلاحيات `LocalSystem` لتنفيذ الأوامر الموقعة فقط، وإدارة قفل الشاشة، ومراقبة صحة الجهاز والشبكة.
- **CyberCenter.Shell:** واجهة ألعاب جذابة وفاخرة تمنح اللاعب وصولاً سريعاً لألعابه وطلبات المتجر وحسابه دون مغادرة البيئة الآمنة.
- **CyberCenter.HUD:** شريط معلومات شفاف لا يحجب شاشات الألعاب يعرض الوقت المتبقي، استهلاك البيانات، وحالة الاتصال بأمان تام ودون حقن للذاكرة.

## 5. مصفوفة القيمة المضافة ومؤشرات النجاح (Success Criteria)

1. **الاستقرار التشغيلي:** استمرار عمل محطات اللعب دون انقطاع حتى في حال حدوث تذبذب مؤقت في شبكة الخادم المركزي عبر تقنية Session Lease.
2. **الأمان والحماية:** حماية تامة لنظام التشغيل ومنع العبث بساعة ويندوز أو إعدادات النظام الحساسة مع إبقاء الألعاب متوافقة مع جميع برامج مكافحة الغش.
3. **الدقة المالية:** صفر تسرب مالي بفضل إلزامية التسجيل المزدوج والعمليات المشفرة وعدم إتاحة الحذف اليدوي للقيود المعتمدة.
4. **سرعة الاستجابة:** زمن استجابة الأوامر اللحظية (أمر القفل/الفتح، طلبات المتجر) أقل من 300 ملي ثانية عبر بروتوكول SignalR WebSockets.
