# وثيقة متطلبات النظام (System Requirements Document)
## نظام CyberCenter لإدارة مراكز الإنترنت والألعاب

---

## 1. المتطلبات الوظيفية الشاملة (Functional Requirements)

### 1.1. إدارة الأجهزة ومحطات العمل (Device Management)
- **FR-DEV-001 (تسجيل الأجهزة):** تسجيل كل جهاز عميل برقم تعريف فريد (`Device ID` / GUID) وربطه ببصمة عتادية (Machine Name, MAC Address, CPU/RAM Specs, Local IP).
- **FR-DEV-002 (حالات الجهاز):** دعم الحالات التالية بدقة:
  - `Available` (متاح وغير مستخدم)
  - `Occupied` (مشغول بجلسة نشطة)
  - `Reserved` (محجوز)
  - `Maintenance` (تحت الصيانة)
  - `Offline` (غير متصل بالخادم)
  - `Locked` (مقفل بأمر الإدارة)
  - `Error` (حالة خطأ في الـ Agent أو العميل)
- **FR-DEV-003 (مراقبة النبض اللحظية - Heartbeat):** إرسال نبض دوري كل 5 إلى 10 ثوانٍ من الـ Agent إلى الخادم، متضمناً: الذاكرة المستخدمة، المعالج، سرعة الرفع والتحميل، وحالة التطبيق الواجهي.
- **FR-DEV-004 (التحكم عن بُعد الموثق):** إمكانية إرسال أوامر تحكم فورية من لوحة الإدارة إلى الجهاز تشمل:
  - فتح الجهاز (Unlock Station)
  - قفل الجهاز (Lock Station)
  - بدء جلسة محددة (Start Session)
  - إنهاء جلسة قسرياً (Terminate Session)
  - تمديد وقت الجلسة (Extend Time)
  - إرسال رسالة فورية تظهر كـ Alert للعميل (Send Notification Message)
  - إعادة تشغيل / إيقاف تشغيل الجهاز (Reboot / Shutdown) مع تسجيل هوية المشرف والسبب.

---

### 1.2. إدارة الحسابات والجلسات (Account & Session Management)

#### A. الجلسات المفتوحة (Open Sessions)
- **FR-SES-001:** فتح المحطة بدون حد زمني مسبق بواسطة المشرف/الكاشير.
- **FR-SES-002:** احتساب تكلفة الوقت تراكمياً بدقة الدقيقة وفق تسعيرة المركز المعتمدة.
- **FR-SES-003:** إنهاء الجلسة يدوياً من الإدارة عند مغادرة العميل ودفع الحساب.

#### B. الكروت المؤقتة مسبقة الدفع (Temporary Cards)
- **FR-SES-004 (التوليد الآمن):** توليد دفعات كروت (Batches) برموز PIN عشوائية مشفرة مكونة من 16 رقماً، غير متتالية ومحمية ضد التخمين (Rate Limiting).
- **FR-SES-005 (المدد القياسية والمخصصة):** دعم مدد جاهزة (30 دقيقة، 1 ساعة، 1.5 ساعة، 2 ساعة، 3 ساعات) أو أي مدة مخصصة بالدقائق.
- **FR-SES-006 (حالات الكرت):** تتبع حالة الكرت بدقة (`Unused`, `Active`, `Depleted`, `Expired`, `Revoked`).
- **FR-SES-007 (أمان الـ PIN):** تخزين الـ PIN مشفراً بخوارزمية تجزئة قوية (BCrypt أو Argon2id أو HMAC-SHA256 مع Salt) وعدم إظهار الـ PIN بالكامل في سجلات التدقيق أو الشاشات العامة، مع إمكانية تصدير الكروت وطباعتها PDF / Excel فور توليدها فقط.
- **FR-SES-008 (الرصيد الزمني القابل للخصم):** إمكانية استخدام الكرت على فترات متعددة حتى نفاد الدقائق المتبقية مع منع الاستخدام المتزامن لنفس الكرت على أكثر من جهاز.

#### C. حسابات الأعضاء الدائمين (Members)
- **FR-SES-009:** تسجيل حسابات دائمة ببيانات: اسم المستخدم، الاسم الكامل، الهاتف، البريد الإلكتروني (اختياري)، وكلمة المرور المشفرة.
- **FR-SES-010 (الخطط والاشتراكات):** دعم اشتراكات زمنية: يومية، أسبوعية، شهرية، وباقات ساعات مسبقة الدفع (Prepaid Balance).
- **FR-SES-011:** سجل شامل لكل عضو: أرشيف الجلسات، سجل الشحن والمدفوعات، طلبات المتجر، ومستوى العضوية (Tier / VIP).
- **FR-SES-012:** إيقاف وتفعيل الحسابات من قبل الإدارة مع توثيق السبب في سجل التدقيق.

### 1.3. دورة حياة الجلسة وإدارة الوقت (Session Lifecycle & Timing)
- **FR-TIM-001 (مصدر الحقيقة الموحد):** خادم المركز المركزي هو المصدر الوحيد والنهائي للوقت والحساب؛ لا يتم الاعتماد مطلقاً على ساعة ويندوز المحلية للأجهزة العميلة.
- **FR-TIM-002 (عقود الإيجار الزمنية - Cryptographic Session Leases):** تزويد جهاز العميل بعقد زمني موقع رقمياً (Signed Lease Token) بمدة صلاحية قصيرة (مثلاً 60 ثانية) يتم تجديده دورياً عبر الـ Heartbeat. في حال انقطاع الشبكة، يسمح للجهاز بالاستمرار للفترة المحددة في سياسة عدم الاتصال (Offline Grace Period) ثم يقفل المحطة تلقائياً إذا تعذر الوصول للخادم لمنع اللعب المجاني.
- **FR-TIM-003 (التنبيهات التحذيرية):** إرسال إشعارات صوتية ومرئية في الـ HUD قبل انتهاء الوقت بـ 10 دقائق و 5 دقائق ودقيقة واحدة.
- **FR-TIM-004 (إنهاء الجلسة والتنظيف):** عند انتهاء الوقت، يتم إغلاق ألعاب التطبيقات فوراً وحجب سطح المكتب بشاشة القفل الموحدة، مع تفعيل آلية تنظيف الملفات المؤقتة للزوار.

---

### 1.4. المتجر الداخلي ونقاط البيع (Store & POS)
- **FR-STR-001 (كتالوج المنتجات):** إدارة المنتجات المصنفة (مشروبات ساخنة، عصائر وبارد، مياه، وجبات سريعة وساندويتشات، إكسسوارات) بالاسمين العربي والإنجليزي، السعر، الصورة، حالة التوفر، والكمية بالمخزن.
- **FR-STR-002 (سلة المشتريات بالعميل):** واجهة مدمجة في شاشة العميل تتيح استعراض المنتجات، تحديد الكميات، تدوين ملاحظات خاصة (مثلاً: بدون سكر)، وعرض الإجمالي وإرسال الطلب مباشرة من المحطة.
- **FR-STR-003 (شاشة المطبخ والكاشير - Kitchen KDS):** لوحة تفاعلية فورية لتحديث حالات الطلبات:
  `New` ➔ `Awaiting Payment` ➔ `Paid` ➔ `Preparing` ➔ `Ready` ➔ `Delivered` ➔ `Cancelled`
  مع إشعارات صوتية فورية وإشعار العميل على شاشته بكل تحديث لحظياً.

---

### 1.5. المدفوعات والوحدة المالية (Payments & Financial Management)
- **FR-FIN-001 (طرق الدفع المتعددة):**
  - نقد (Cash)
  - رصيد المحفظة / العضو (Wallet Balance)
  - دفع يدوي / محلي (Manual Payment: تحويلات الكريمي أو الصرافين المحليين برقم العملية وإشعار المحاسب)
  - بوابات دفع إلكترونية (Online Gateways) عند توفر الاعتماد الرسمي.
- **FR-FIN-002 (التحقق والاعتماد الصارم):** حظر اعتماد أي دفع يدوي كـ "مدفوع" بشكل آلي؛ تتطلب التحويلات مراجعة واعتماد المحاسب المسؤول مع توثيق مرجع الحوالة.
- **FR-FIN-003 (المصروفات والتسويات):** تسجيل المصروفات اليومية (كهرباء، صيانة، مشتريات بوفيه، إيجارات) مع ربطها بالمشرف القائم بالصرف.
- **FR-FIN-004 (التقارير المالية المتقدمة):** تقارير إيرادات الجلسات، اشتراكات الأعضاء، مبيعات المتجر، صافي الأرباح اليومية والشهرية، مع رسوم بيانية تفاعلية وفلاتر زمنية.
- **FR-FIN-005 (الإقفال الشهري المعتمد):** إجراء محاسبي دوري لاعتماد نتائج الشهر وتثبيتها من قِبل الـ Super Admin، مما يمنع التعديل على القيود السابقة ويفرض قيود تسوية عكسية عند الحاجة للتصحيح.

---

### 1.6. مراقبة الشبكة وتقدير استهلاك الطاقة (Network & Energy)
- **FR-NET-001 (مراقبة استهلاك البيانات):** قياس استهلاك التحميل (Download) والرفع (Upload) والسرعة اللحظية لكل جهاز على مدار الجلسة واليوم والشهر.
- **FR-NET-002 (تقارير الشبكة وجودة الخدمة):** تصنيف أكثر الأجهزة استهلاكاً للباندويث وتوفير أرضية للتكامل مع بوابات التوجيه (MikroTik / RouterOS API).
- **FR-ENG-001 (حسابات الطاقة الكهربائية):** إمكانية إدخال تسعيرة الكيلوواط/ساعة (kWh)، وتسجيل قراءات العدادات الذكية أو القراءات اليدوية الدورية، مع إظهار الفرق بدقة وشفافية بين "الاستهلاك المقاس بالعداد" و"الاستهلاك التقديري الحسابي للأجهزة".

---

### 1.7. الأمان وإدارة الصلاحيات (Security, Roles & Audit)
- **FR-SEC-001 (مستويات الصلاحيات الصارمة):**
  - **Super Admin:** صلاحيات مطلقة للإعدادات والماليات والنسخ الاحتياطي وحسابات الموظفين.
  - **Admin / Cashier:** صلاحيات تشغيلية فقط لإدارة الجلسات وطلبات المتجر دون صلاحية حذف السجلات أو إقفال الفترات المالية.
- **FR-SEC-002 (سجل التدقيق غير القابل للتلاعب - Immutable Audit Log):** تسجيل كل عملية إدارية حساسة (اسم الموظف، نوع العملية، التاريخ والوقت UTC، الجهاز المرتبط، القيمة السابقة والجديدة، النتيجة) وحمايته من التعديل أو الحذف.
- **FR-SEC-003 (تذاكر الدعم والمساعدة):** إمكانية إرسال العميل لطلب مساعدة بضغطة زر من الـ Quick Menu، مع تصنيف المشكلة وإشعار المشرفين فوراً.

## 2. المتطلبات غير الوظيفية (Non-Functional Requirements)

| المعيار (Metric) | المتطلب المحدد |
| :--- | :--- |
| **الأداء والاستجابة (Performance)** | - زمن استجابة API لا يتجاوز 150ms في 95% من الطلبات.<br>- زمن وصول الأوامر الفورية عبر SignalR لا يتجاوز 300ms.<br>- استهلاك الذاكرة لتطبيق العميل لا يتجاوز 120MB في وضع الخمول. |
| **التوافر والاستمرارية (Availability)** | - توافر الخادم بنسبة 99.9% في بيئة الشبكة المحلية.<br>- صمود الأجهزة العميلة عند انقطاع الشبكة لمدة محددة تمنع إحباط اللاعبين أثناء الجولات الحاسمة. |
| **الأمان ومكافحة التلاعب (Security)** | - تشفير كامل للاتصالات (HTTPS / WSS / TLS 1.3).<br>- تخزين كلمات المرور بتشفير BCrypt عالي التكلفة.<br>- منع العبث بساعة النظام أو ملفات التطبيق من خلال تشغيل واجهة العميل بحساب Standard User وخدمة الـ Agent بحساب System. |
| **سلامة الألعاب (Anti-Cheat Compliance)** | - حظر تام لأي تقنية حقن ذاكرة (No DLL Injection / No Memory Hooking).<br>- تشغيل شريط الـ HUD بأسلوب Borderless Transparent Overlay متوافق مع Riot Vanguard و Easy Anti-Cheat. |
| **تجربة المستخدم واللغات (i18n & UX)** | - دعم كامل ومتقن للغة العربية (RTL) مع خط Cairo / IBM Plex Sans.<br>- دعم كامل للغة الإنجليزية (LTR) مع تبديل لحظي بنقرة زر واحدة.<br>- واجهة Dark Premium فخمة مريحة للعين في البيئات المظلمة. |
| **التوافقية (Compatibility)** | - الخادم: يعمل على Windows Server أو Linux (Ubuntu / Debian / Docker).<br>- العميل: يعمل بكفاءة على Windows 10 (64-bit) و Windows 11 بكافة التحديثات الحديثة. |
